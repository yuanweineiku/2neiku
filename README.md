# 2neiku
## 二手内裤 2neiku.com

2neiku.com 是一个出售女生二手贴身衣物的网站，网址 2neiku 的含义是“二手内裤”。

二手衣物也叫原味衣物，最畅销的包括：原味内裤、原味丝袜、原味内衣、原味袜子等。

为了方便恋物买家辨别真假，网站里面发布了很多衣物的真实痕迹照片（能看到脏旧程度），原味商品也只有能看清细节的高清图才可以判断是否是真的。

请注意，**只出衣物，不涉及任何违规内容，无任何大尺度内容**。正经卖家，只出闲置衣物，不要和那些乱七八糟的盗图和诈骗网站相提并论！
